# مصاريفي — Android project

تطبيق أندرويد عربي لإدارة الدخل والمصاريف، مع تخزين محلي داخل الجهاز باستخدام SQLite.

## الوظائف
- شاشة الاستعلام الرئيسية تعرض رصيد الخزنة، دخل الشهر، المصروفات، والمتبقي من دخل الشهر.
- اختيار شهر لعرض مصروفاته أو اختيار فترة مخصصة بالتاريخ.
- إضافة المصروف وتعديله وحذفه، مع المبلغ والتاريخ والتصنيف والملاحظات.
- إدارة رصيد الخزنة الافتتاحي والدخل اليدوي حسب المصدر والتاريخ والملاحظات.
- إضافة التصنيفات وتعديلها وحذفها.

## فتح المشروع
افتح مجلد `PocketLedger` في Android Studio، ثم اسمح بمزامنة Gradle، وبعدها استخدم **Build > Build APK(s)** لإنشاء ملف APK.

يتطلب البناء Android SDK 35 وJDK 17 أو أحدث. لا يحتاج التطبيق إلى اتصال شبكة أثناء الاستخدام؛ البيانات محفوظة في قاعدة SQLite على الجهاز.
